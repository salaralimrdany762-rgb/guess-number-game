# بازی حدس اعداد (نسخه گسترش‌یافته)

پروژه ۱ درس کارگاه کامپیوتر — گسترش بازی حدس اعداد با زبان پایتون.

## اجرا

نیاز به Python 3.6 یا بالاتر (بدون کتابخانه اضافه):

```bash
python guess_game.py
```

## امکانات

| # | قابلیت | توضیح |
|---|--------|-------|
| ۱ | محدودیت تلاش | عدد مخفی تصادفی بین ۱ تا ۱۰۰؛ حداکثر ۵ فرصت |
| ۲ | نمایش وضعیت | قبل از هر حدس: «تلاش X از ۵» و «جان باقی‌مانده» |
| ۳ | راهنمای هوشمند | اختلاف ≤ ۵: «خیلی نزدیکی!» — اختلاف ≤ ۱۵: «نزدیکی، ولی هنوز فاصله داری!» — بیشتر: «خیلی دوری!»؛ همراه با «بزرگ‌تر/کوچک‌تر وارد کن» |
| ۴ | رتبه‌بندی | تلاش ۱: نمونه‌ای — ۲: بسیار خوبی — ۳: خوب — ۴: قبول — ۵: با شانس بردی! (در صورت باخت رتبه‌ای داده نمی‌شود) |
| ۵ | نمایش عدد در باخت | بعد از ۵ حدس غلط، عدد مخفی نمایش داده می‌شود |
| ۶ | بازی مجدد | بعد از هر دور می‌پرسد «بله/خیر»؛ دور جدید با عدد تازه و ۵ فرصت |
| ۷ | اعتبارسنجی ورودی | حروف، متن، اعشار، ورودی خالی و اعداد خارج از ۱ تا ۱۰۰ رد می‌شوند و از فرصت‌ها کم نمی‌کنند |

نکته‌های اضافه: ارقام فارسی (مثل `۴۲`) هم پذیرفته می‌شوند، و با Ctrl+C برنامه بدون پیام خطا بسته می‌شود.

## ساختار کد

- `get_guess()` — گرفتن و اعتبارسنجی حدس
- `closeness_hint()` و `direction_hint()` — راهنمای نزدیکی و جهت
- `play_round()` — اجرای یک دور بازی
- `ask_play_again()` — پرسیدن برای بازی مجدد
- `main()` — حلقه اصلی برنامه

آستانه‌ها و تعداد فرصت‌ها به‌صورت ثابت در ابتدای فایل تعریف شده‌اند و به‌راحتی قابل تغییرند.
